# Estudos de Java

Exercícios feitos enquanto aprendia Java, em 2024.

| Pasta | Conteúdo |
|---|---|
| `devdojo curso/` | Exercícios do curso de Java do DevDojo: tipos primitivos, operadores, condicionais, laços, arrays, classes, métodos, sobrecarga e construtores |
| `prova/` | Exercícios de prova: calculadora, conversor de temperatura, validação de senha, cálculo de IR, equação de 2º grau e clube de campo |

Os exercícios de orientação a objetos seguem a separação em `dominio/` (classes) e `test/` (classes com `main` que usam as do domínio).
